FiestaPanel Addon Developer Guide & API Reference [ Download Starter Kit (.zip) ]

FiestaPanel provides a lightweight, powerful extension system. Build custom views, console hooks, and automated tools with Python and standard HTML.

1. Addon Directory Structure

Addons live in addons/<addon_id>/. A minimal working addon requires only addon.json and optional main.py / tab.html:

addons/
└── my_custom_addon/
    ├── addon.json       # Required: Manifest with name, version, and schema
    ├── main.py          # Optional: Python backend logic & on_action hooks
    ├── tab.html         # Optional: Custom UI rendered in panel tab
    └── custom.css       # Optional: Custom DOM styles injected automatically
2. Manifest Specification (addon.json)
{
  "id": "my_announcer",
  "name": "Server Auto-Announcer",
  "version": "1.0.0",
  "author": "YourName",
  "description": "Periodically broadcasts custom announcement messages to all players in-game.",
  "icon": "fas fa-bullhorn",
  "category": "Automation",
  "enabled": true,
  "entrypoint": "main.py",
  "settings_schema": [
    { "key": "msg", "label": "Announcement Text", "type": "text", "default": "Welcome!" }
  ],
  "default_settings": {
    "msg": "Welcome to our server!"
  },
  "ui_slots": {
    "tab": {
      "title": "Announcer",
      "icon": "fas fa-bullhorn",
      "description": "Configure automated announcements and test live chat broadcasts."
    }
  }
}
3. Backend Python Hooks (main.py)
def init_addon(ctx):
    ctx.logger.info("Addon initialized!")

def on_action(ctx, action_name, payload):
    if action_name == "broadcast":
        msg = payload.get("message") or ctx.get_settings().get("msg", "Hello")
        success, response = ctx.send_command(f"say {msg}")
        return {"success": success, "message": "Broadcast sent!" if success else response}
    return {"success": False, "error": f"Unknown action: {action_name}"}
4. Frontend AJAX Communication

Inside your tab.html, trigger backend actions effortlessly with standard fetch():

fetch('/api/panel-addons/my_announcer/action', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ action: 'broadcast', payload: { message: 'Hello from web!' } })
})
.then(res => res.json())
.then(data => alert(data.message || data.error));
5. How to Publish Your Addon to the Official FiestaPanel Store

Ready to share your addon with all FiestaPanel servers worldwide? To keep all servers secure and stable, direct publishing to the official repository is locked for Fiesta team administrators. All community extensions go through a manual verification and approval process.

  1. Package as ZIP: Compress your addon directory into a .zip file containing addon.json, main.py, tab.html, and README.md.
  2. Submit for Review: Submit a Pull Request to our GitHub repository (open-fiestasmp/FiestaPanel ↗) or send your .zip archive directly to the Fiesta team on our Discord server.
  3. Approval & Publishing: The FiestaSMP core team will review, security-audit, test, and approve the sent .zip file. Once approved, the team will deploy it directly to the official Plugin Store catalog so users can One-Click install it!
